# Kotoba Lab KR (비공식 한국어화 초판)
원본: https://github.com/onuresen/kotoba-lab (10.49.2, MIT). 원본 LICENSE 및 data/ATTRIBUTION.md, 사전과 획순 데이터의 CC BY-SA 조건을 유지합니다. 한국어화 변경: 메뉴/주요 UI 번역, 일부 자체 작성 한국어 훈음/단어 뜻 병기, 별도 오프라인 캐시. 원본 데이터는 수정하지 않았습니다.

## 배포
새 공개 GitHub 저장소를 만들고 ZIP의 내부 파일 및 폴더를 루트에 업로드합니다. Settings → Pages → Deploy from a branch → main → /(root) → Save. 기존 漢字の輪 저장소를 덮어쓰지 마세요. 로컬에서는 `node serve.mjs`로 실행합니다.

## 제한
한국어화는 일부입니다. 동적으로 생성되는 일부 문구 및 미등록 사전 뜻은 영어입니다. 자동 번역을 사용하지 않습니다. 원본 단어 및 한자 데이터 전체를 유지합니다. 한국어 단어 뜻은 대표 뜻이며 문맥별 모든 의미를 검수한 것은 아닙니다.

## 확인 결과
원본 자동 테스트 427개 통과 (캐시 및 저장소 이름 분리에 맞춰 관련 테스트 수정). Chromium 실제 화면 테스트는 실행 환경의 URL 접근 제한으로 수행하지 못했습니다. 한국어 훈음 적용 365/6813자, 한국어 대표 단어 뜻 적용 142/10808개 (사전 항목 기준). 기존 데이터는 삭제하지 않았습니다.
